CARA MENGGANTI FOTO PROFIL:
==============================
1. Siapkan foto profil Anda (format JPG/PNG).
2. Beri nama file tersebut: "profile.jpg"
3. Letakkan file "profile.jpg" di dalam folder ini ("assets/").
4. Muat ulang (refresh) halaman website Anda di browser.

Foto profil Anda akan langsung tampil secara otomatis dengan bingkai aesthetic pastel!
Jika file foto belum diletakkan di sini, website akan otomatis menampilkan avatar inisial (AN) yang rapi dan elegan.
